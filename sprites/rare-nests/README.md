# ฐานไข่แรร์ (รอ implement พร้อมกันทั้ง 3 แบบ)

สถานะ: 🌈 รุ้งคริสตัล + ยูนิคอร์น = KC อนุมัติหน้าตาแล้ว (`demo-rainbow.html`) · 🔥 รังมังกร = รอภาพนิ่ง · แบบที่ 3 = KC จะหาแบบใหม่ (ตัดเบาะกำมะหยี่ทิ้ง — ยังไม่สวย)
ได้จากไข่หายากเท่านั้น (ไม่ขายในร้าน) · ใส่เข้าแอปพร้อมกันทั้ง 3 แบบ

## ไฟล์
| ไฟล์ | คือ |
|---|---|
| `rainbow.webp` | แท่นรุ้งคริสตัล (ตัดพื้นม่วงแดงแล้ว กว้าง 360) · rim ≈ .55 · ไข่ 54px |
| `unicorn-fly.webp` | ยูนิคอร์นบิน 4 ช่อง เรียงแบบลูปไป-กลับแล้ว (ปีกขึ้น → กาง → หุบครึ่ง → กาง) · ช่องละ 135×150 |
| `demo-*.html` | ตัวอย่างที่ KC ดูแล้ว (เปิดในเบราว์เซอร์ได้เลย) — ใช้เป็นต้นแบบตอนเขียนเข้าแอป |

## สูตรที่ใช้ (ทุกแบบแรร์)
- **ภาพนิ่ง 1 ภาพ + เอฟเฟกต์ด้วยโค้ด** ดีกว่าชีตทั้งตัว (ชีตที่เจนมาหน้าตาไม่ตรงกันทุกเฟรม · ขอบขาวบางลงตอนตัดพื้นเขียว)
- **ตอนปกติหรู+นิ่ง แล้วมี "ช่วงพีค" ทุก ~7–8 วิ** (เอฟเฟกต์เล็ก ๆ เยอะ ๆ พร้อมกันตลอด = รก ไม่ว้าว)
  - ปกติ: สปอตไลต์ส่องลง + แอ่งแสงบนพื้น · ของลอยเหนือ/รอบไข่ (ยูนิคอร์น / ลูกไฟ) · แสงวิ่งผ่านตัวฐาน (mask ด้วยภาพฐาน) · ฐานเรืองแสงเป็นจังหวะ
  - พีค: ฐานเด้ง (squash) → เอฟเฟกต์ใหญ่ทั้งห้อง (วงแสงทอง / รุ้งโค้งข้ามห้อง / ไฟพุ่ง) → ดาวพุ่งเป็นพัด
- ตัดทิ้ง: รัศมีหมุนด้านหลัง, ดาวโคจร (ดูรก/ถูก)
- 🔥 รังมังกร: ของลอย = ลูกไฟวน · พีค = เปลวไฟพุ่งเป็นวง + ถ่านไฟโปรย

## ปัญหาที่เจอ + วิธีแก้ (เช็กทุกครั้งกับแบบใหม่)
1. **ไข่ลอยเหนือแอ่ง / มีฐานซ้อน 2 ชั้น** → ซ่อนฐานไม้ของไข่ (`svg > ellipse:first-child`) + ฐาน 2 ชั้น (ภาพเต็มหลังไข่ · ภาพเดิมตัดเหลือส่วนใต้ขอบหน้าแอ่ง `clip-path:inset(rim 0 0 0)` วางทับก้นไข่) · ตั้ง `rim` ต่อแบบ + ปรับขนาดไข่ถ้าไข่บังของด้านหลังแอ่ง
2. **ฐานแบบมีรูทะลุ (โดนัท)** ไข่ดูลอย → ใช้ฐานที่แอ่งปิด · prompt ต้องมี "closed shallow dip, NOT a hole" + "Only ONE …"
3. **ตัวละครในชีตกระตุกซ้าย-ขวาทุกเฟรม** → อย่าจัดกลางตามกรอบ (ปีกกางไม่เท่ากัน = กรอบกว้างไม่เท่ากัน) · จัดเฟรมด้วย **หัว** เป็นจุดอ้างอิง (template matching หน้าเฟรม 1 กับเฟรมอื่น)
4. **รอยต่อท่ากระตุก** (เฟรมที่ท่าต่างมาก เช่นปีกมาอยู่หน้าท้อง) → ตัดเฟรมนั้นทิ้ง แล้วเรียงเป็น **ลูปไป-กลับ** ให้ทุกการเปลี่ยนเฟรมเป็นท่าที่อยู่ติดกัน
5. **ของที่บินวน "วาป" ข้ามตำแหน่ง** ตอนเปลี่ยนความเร็ว (ช่วงพีค) → ห้ามคำนวณ `มุม = เวลา × ความเร็ว` · ใช้ `มุม += dt × ความเร็ว` ทุกเฟรม + ค่าเร่ง (boost) ค่อย ๆ ไล่ไปหาเป้า (ease) ไม่ตั้งทันที · ตรวจโดยวัดระยะขยับต่อเฟรม (ต้อง < ~5px ไม่มีกระโดด)
6. **ขนาด/หันตัวกระโดดตอนอ้อมหลังฐาน** → ขนาดตามระยะแบบต่อเนื่อง (`s = .86 + .14·sin(มุม)`) · หันตัวด้วย scaleX ที่ไล่ค่าไปหาเป้า (ผ่านแนวข้าง)
7. **ปีกในชีตไม่ขยับ** → prompt 4 เฟรมที่ระบุท่าปีกสุดขั้วทีละเฟรม (ขึ้นสุด / กางตรง / ลงสุด / หุบครึ่ง) · ถ้ายังไม่ได้: เจนตัวไม่มีปีก + ปีกข้างเดียว แล้วโค้ดกระพือ
8. **บินเร็วเกิน** → วนรอบละ ~10 วิ · กระพือ 0.7 วิ/รอบ
9. หางสายรุ้ง: ริบบิ้น 6 เส้นบน canvas 2 ชั้น (หลังฐาน/หน้าฐาน ตามตำแหน่ง) แทนจุดแยก
