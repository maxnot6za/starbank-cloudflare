# ธีม (public/themes/)

ธีม = ภาพพื้นหลัง + เพลง + เอฟเฟกต์ + มาสคอตน้องดาว + คำเรียก + เกม 5 วัน + ป๊อปอัปฉลอง
ผู้ปกครองเลือกในตั้งค่า → `Families.theme` → ทุกเครื่องในครอบครัวเปลี่ยนตามทันที (Live)

```
themes/
  index.json            รายชื่อธีมที่ให้เลือก (ต้องตรงกับ THEMES ใน src/core.js)
  <id>/theme.json       ธีมนี้ใช้ไฟล์อะไร (ดูตัวอย่าง xmas/theme.json)
  <id>/...              ไฟล์ของธีม
```

## เพิ่มธีมใหม่ — สิ่งที่ KC ต้องส่งให้ Claude

> Claude: เมื่อ KC พูดว่า "เพิ่มธีม" ให้ส่งรายการนี้ให้ KC ก่อนเสมอ แล้วตรวจของที่ได้รับตามรายการ

### 1. ข้อมูลธีม (พิมพ์มาในแชตได้เลย)
- ชื่อธีมภาษาไทย + อีโมจิ 1 ตัว (เช่น "สงกรานต์ 💦")
- เอฟเฟกต์บนจอ: ของที่ร่วงลงมา 2–4 แบบ (เป็นอีโมจิหรือตัวอักษร เช่น 💧 🌸) + สี หรือ "ไม่มี"
- คำเรียกเกม 5 วัน (แทนคำของคริสต์มาส):

| คำ | คริสต์มาส | ตัวอย่างสงกรานต์ |
|---|---|---|
| ชื่อเกม (board) | ต้นคริสต์มาส | ขันน้ำ |
| ของที่สะสม (item) | ลูกบอล | หยดน้ำ |
| ลักษณนาม (unit) | ลูก | หยด |
| คำกริยาเวลาได้ 1 วัน (add) | แขวน | เติม |
| ข้อความตอนครบ (full) | ต้นไม้ครบ 5 ลูก ดาวสว่างแล้ว! | ขันน้ำเต็มแล้ว! |
| ป๊อปอัป: ป้ายบน / หัวข้อ / ข้อความ | 🎄 ภารกิจต้นคริสต์มาส / ครบ 5 วันแล้ว! 🎉 / ต้นไม้ของหนูสว่างไสวเลย เก่งมาก! | … |

### 2. ไฟล์ภาพและเสียง
| ไฟล์ | จำนวน | สเปก |
|---|---|---|
| พื้นหลัง | 1 | แนวตั้ง ประมาณ 1536×2730 (9:16) jpg · ด้านบนโล่ง/สว่าง เพราะมีการ์ดทับ · ฉากหลักอยู่ครึ่งล่าง |
| เพลงพื้นหลัง | 1 | mp3 วนลูปได้ 1–3 นาที ≤ 3MB · **ต้องมีสิทธิ์ใช้** (royalty-free) · บอกแหล่งที่มา |
| มาสคอตน้องดาว | 4 ท่า | ท่าเดียวกับชุดเดิม: ไป!(go) · หลับ/ไม่เป็นไร(sleep) · หมดเวลา(timeout) · ดีใจ(yay) · พื้นโปร่งใสหรือพื้นสีเรียบ · ใส่ของประจำธีม (เช่นหมวก) |
| เกม 5 วัน | 6 รูป | สภาพ 0/5, 1/5, 2/5, 3/5, 4/5, 5/5 (เต็ม) · มุมกล้อง ขนาด ตำแหน่งเหมือนกันทุกรูป · พื้นสีเรียบ |
| ป๊อปอัปฉลอง | 4–8 เฟรม | ช่วงที่ของชิ้นสุดท้ายถูกเติมจนเต็มและฉลอง · ขนาด/ตำแหน่งเหมือนกันทุกเฟรม · ทำในภาพเดียวแถวเดียวได้ (Claude ตัดให้) |
| (ไม่บังคับ) แบบมีน้องไดโน | 2–4 เฟรม | ท่าลูกไดโนทำกิริยากับของในธีม · ไม่มีก็ได้ จะใช้แบบไม่มีตัวละครแทน |

ใช้ส่วนสไตล์ + พื้นสีเรียบ `#EEF8F4` จาก `sprites/PROMPTS.md` เวลาเจน

## Claude: ขั้นตอนหลังได้ของครบ
1. สร้าง `public/themes/<id>/` (id ภาษาอังกฤษสั้น ๆ) · ตัดพื้นหลังภาพ · ย่อ (`webp`, พื้นหลัง jpg ≤ 400KB) · ทำ `preview.jpg` 320×240
2. เขียน `theme.json` (ดูชนิดด้านล่าง) · เพิ่มใน `index.json` และ `THEMES` ใน `src/core.js`
3. `node test/theme.test.js` (ตรวจไฟล์ครบ) → ถ่ายภาพหน้าจอให้ KC ดูก่อน push · ไม่ต้องมี migration

### ชนิดใน theme.json
- `effect`: `{ "type": "fall", "chars": [...], "color": "#hex", "count": 25 }` หรือ `{ "type": "none" }`
- `progress`: `{ "type": "images", "frames": ["p0.webp", …, "p5.webp"] }` (คริสต์มาส = `builtin-xmas-tree` วาด SVG ในโค้ด)
- `celebrate`: `{ "type": "frames", "frames": ["c1.webp", …], "ms": 500 }` เล่นทีละเฟรมแบบเฟดแล้วค้างเฟรมสุดท้าย
  (คริสต์มาส = `builtin-xmas-tree` + `dir` อนิเมชัน canvas ใน `treePopOpen` มีแบบน้องไดโน)
- `words`: ขาดคำไหนใช้คำของคริสต์มาสแทน
